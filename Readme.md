# RicheyData Admin

Admin dashboard for [RicheyData](https://richeydata.shop), a Ghana data bundle store. It is used by staff to manage orders, customers, bundles and prices.

**This app is for authorised staff only.** The customer-facing site lives in a separate repository: [`richeydata`](https://github.com/AndohBlay/richeydata).

## Features

- Staff login (admin accounts only)
- View and manage orders and their status
- View customers and their accounts
- Manage data bundles and service prices (customer and reseller/agent pricing)
- Monitor SMS and payment activity

## Tech stack

- **Frontend:** React + Vite
- **Backend / database / auth:** Supabase (shared with the customer site)
- **Hosting:** Vercel at `admin.richeydata.shop`
